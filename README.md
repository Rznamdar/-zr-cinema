# Z&R Cinema — نسخه اولیه با چت و تماس

## انتشار رایگان با GitHub Pages
1. وارد GitHub شوید و یک repository عمومی با نام `zr-cinema` بسازید.
2. فایل‌های `index.html`، `style.css` و `app.js` را در ریشه مخزن بارگذاری کنید.
3. در Settings → Pages، گزینه Deploy from a branch را انتخاب کنید؛ Branch را `main` و پوشه را `/root` بگذارید.
4. پس از انتشار، آدرس HTTPS را روی آیفون و اندروید باز کنید.

## استفاده
- یک نفر اتاق بسازد و کد را برای نفر دوم بفرستد.
- نفر دوم کد را وارد کند و به اتاق بپیوندد.
- چت زنده زیر فیلم قرار دارد.
- تماس صوتی یا تصویری را شروع کنید؛ طرف مقابل باید مجوز مرورگر را تأیید کند.
- برای فایل محلی، هر دو نفر باید همان فایل را روی دستگاه خود انتخاب کنند.

## محدودیت‌های مهم
- این نمونه اولیه از PeerJS و سرور عمومی سیگنالینگ استفاده می‌کند؛ در دسترس بودن و پایداری آن تضمین‌شده نیست.
- تماس صوتی/تصویری در این نسخه با درخواست تماس از سمت آغازکننده شروع می‌شود. بهتر است برای تماس واقعی هر دو طرف وارد اتاق باشند و صفحه را باز نگه دارند.
- تماس به HTTPS، اجازه مرورگر و کیفیت اینترنت/NAT دو طرف وابسته است.
- چت فقط تا وقتی صفحه و اتصال اتاق فعال است نگهداری می‌شود و تاریخچه دائمی ندارد.
- فایل محلی به دستگاه دیگر آپلود نمی‌شود؛ هر دو نفر باید فایل یکسان داشته باشند.
- لینک مستقیم MP4/WebM بهترین شانس پخش دارد. بسیاری از سایت‌های فیلم پخش داخل صفحه دیگر را مسدود می‌کنند.
- همگام‌سازی پخش پایه است و ممکن است بافر یا تأخیر اینترنت باعث اختلاف جزئی شود.
- برای محصول قابل اتکا و خصوصی‌تر، بعداً باید سیگنالینگ/سرور TURN و احراز هویت اختصاصی اضافه شود.
