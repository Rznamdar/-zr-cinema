# Z&R Cinema — نسخه اصلاح‌شده

## انتشار روی GitHub Pages
1. ZIP را استخراج کنید.
2. وارد پوشه `zr_cinema` شوید.
3. چهار فایل `index.html`، `style.css`، `app.js` و `README.md` را در ریشه همان Repository قبلی آپلود کنید و گزینه **Replace** را برای فایل‌های هم‌نام بزنید.
4. تغییرات را Commit کنید و چند دقیقه برای انتشار GitHub Pages صبر کنید.
5. هر دو نفر لینک HTTPS سایت را باز کنند.

## ورود به اتاق
- یک نفر فقط یک بار «ساخت اتاق جدید» را بزند و صفحه را باز نگه دارد.
- کد نمایش‌داده‌شده را برای نفر دوم بفرستد.
- نفر دوم همان کد را وارد کند و «ورود به اتاق» را بزند.
- تا وقتی هر دو در اتاق هستند، صفحه را نبندید یا Refresh نکنید.

## پخش فیلم
- لینک مستقیم MP4، WebM و برخی فرمت‌های پشتیبانی‌شده در پلیر اصلی پخش می‌شوند و همگام‌سازی پخش/توقف/جلو و عقب رفتن برای این حالت فعال است.
- لینک‌های رایج آپارات مثل `https://www.aparat.com/v/VIDEO_ID` به نشانی Embed تبدیل می‌شوند.
- لینک‌های Embed دیگر نیز در iframe باز می‌شوند، اگر سایت منبع اجازه نمایش در سایت خارجی را بدهد.
- بعضی سایت‌ها با سیاست‌های امنیتی خود (مانند X-Frame-Options یا CSP) نمایش در iframe را مسدود می‌کنند؛ این محدودیت از سمت سایت منبع است و با تغییر کد صفحه قابل دور زدن نیست.
- کنترل زمان پخش و همگام‌سازی برای پلیرهای Embed خارجی تضمین نمی‌شود؛ این قابلیت به API همان سرویس نیاز دارد.
- برای فایل محلی، هر دو نفر باید همان فایل را جداگانه روی گوشی خود انتخاب کنند؛ فایل به سرور ارسال نمی‌شود.

## چت و تماس
- چت زنده تا زمان باز بودن نشست و اتصال فعال است و تاریخچه دائمی ندارد.
- تماس صوتی/تصویری به HTTPS، مجوز میکروفون/دوربین، مرورگر و تنظیمات شبکه وابسته است.
- این نسخه از PeerJS و سرور عمومی آن برای هماهنگی اتصال استفاده می‌کند و چند STUN عمومی دارد. دسترسی یا پایداری این سرویس‌ها تضمین‌شده نیست.
- در شبکه‌هایی که ارتباط P2P را محدود می‌کنند، ممکن است به سرور TURN اختصاصی نیاز باشد؛ این نسخه TURN اختصاصی ندارد.
